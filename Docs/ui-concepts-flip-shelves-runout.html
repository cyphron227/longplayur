Concept demo, not shipped chrome — three directions to react to
Now Playing — new view mode

Spin to browse. Flip to find.

The dome stays exactly as it is for browsing by feel. Flip is the other half of a record store: alphabetical, searchable, sortable, for when you already know what you're after and don't want to spin for it.

Record bags — reorganised

More crates, grouped like a real shop.

Same card, same 9-cover preview grid you already have. The change is grouping: shelves by canon, mood, and decade instead of one long row, so a bigger library of curated bags stays browsable instead of turning into a scroll.

Runout groove — new screen

Nine ways to go next.

Replaces the plain zoom-to-shelf at the end of an album. Every cell is an honestly labelled direction, not a black-box "you might like." Each label maps to something the app can actually check: same artist, same year, same genre tag, a Deezer-sourced relation, a past keeper, an unplayed pick from the same bag, a followed artist's new release, a deliberate left turn, or a replay.
